# Trabalho de AMC

## Sobre o trabalho
Este trabalho tem como objetivo analisar um computador escolhido na disciplina de Arquitetura e Manutenção de Computadores (AMC).

## Objetivos
- Mostrar os componentes que o computador possui.
- Identificar o que está faltando.
- Analisar o que pode ser melhorado.
- Apresentar possíveis soluções.
- Verificar se o computador está funcionando corretamente.

## Análise
Será realizada uma análise dos componentes, do estado e do funcionamento do computador.

## Conclusão
Apresentar os resultados da análise e as possíveis melhorias para o computador.

## Disciplina
Arquitetura e Manutenção de Computadores (AMC).
